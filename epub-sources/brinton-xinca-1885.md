# グアテマラのシンカ・インディアンの言語と民族学的位置について

ダニエル・G・ブリントン博士

（1884年10月17日、アメリカ哲学協会にて朗読）

〔原刊 p. 89〕

グアテマラ先住民の民族学において、シンカ族がどこに系統づけられるかは、つねに不確かなままであった。シュトル博士は（*Zur Ethnographie der Republik Guatemala*, p. 170, Zürich, 1884）、その言語を調査すれば、この地域の古代住民の移動に新しい光を投げかけうるとの意見を述べている。

しかし今日まで彼らの言語は一語も刊行されておらず、研究者には周囲の諸方言と比較する手段がなかった。幸い私は、この欠をある程度まで補い、この民族について何らかの見解を形づくるのに足る資料を提示することができる。

彼らが正確に居住していたのは、北緯およそ13度50分、西経90度25分で太平洋へ注ぐリオ・デ・ロス・エスクラボスとその支流域、および西はリオ・ミチャトヤトまでであった。その領域はサンタ・ロサ県とフティアパ県の大部分を含み、概略では海岸沿いに約50マイル、内陸のシエラへ約60マイルにわたったといえる。

西では、さほど崩れていないナワトル方言を話すアステカ系のピピル族と接していた。北にはマヤ系のポコマム族がおり、東にはテワンテペク地峡のミヘ族と同族だと考えられてきたポポルカ族の一植民地があった。

彼らの名は Xinca、Xinka、Sinca とさまざまに綴られてきた。最初に挙げた形が正しく、語頭の X は英語 *show* の軟らかい *sh* の音価をもつ。

ベレント博士の写本 *Geografía de las Lenguas Maya-Kiche* によれば、シンカ語は、あるいは現に、あるいはかつて、前述の地域にある次の町村で話されていた。〔原刊 p. 90〕

|  |  |
|---|---|
| Atescatempa | Mustiquipaque |
| Atiquipaque | Nancinta |
| Chiquimulilla | Sinacantan |
| Comapa | Tacuilula |
| Guazacapam | Taxisco |
| Ixguatan | Tepeaco |
| Jupiltepeque | Tescuaco |
| Jutiapa | Tupitepeque |

シンカ族について最初の情報が記されているのは、1524年7月28日付のペドロ・デ・アルバラードからエルナン・コルテスへの書簡である。* そこでアルバラードは、その前年の冬に彼らの領土を征服したことを述べている。この軍事行動のさらに詳しい事情は、フエンテスの写本に基づくフアロス『グアテマラ史』第II巻・第IV編・第22章に記されている。

* 引用は *Biblioteca de autores Españoles*, Vol. XXII, Madrid, 1852 に収録された本文による。

これらの資料から、アルバラードがリオ・ミチャトヤトを渡ってアティキパケの町へ入った後、はじめてシンカ族に遭遇したことがわかる。アルバラードの書簡では Atiepar とされているが、彼は先住民の軍勢と同じくらい、その地名にもひどい損害を与えたのである。

この町で彼は、直前に後にした人々とは別の民族、別の言語に出会ったとはっきり述べている（*este es otra lengua y gente por si*――「これは別の言語であり、それ自体別の民である」）。

そこからタクイルラとタヒスコへ進んだが、フアロスが誤っていうような断固たる抵抗には出会わなかった。アルバラードによれば、先住民は戦わずに彼を迎えたものの、夜になると森へ逃れたからである。しかしタヒスコを離れたのち、彼らは大軍で襲撃し、アルバラードの同盟者を多数殺した。

シンカ族の首邑はナンシンタ――アルバラード書簡の「Nacendelan、大きな町」――であったらしく、あるいはフアロスによればグアサカパンであった。この付近でインディオは頑強に抗戦し、落とし穴を掘り、毒があるといわれる尖った杭を道に植えて、スペイン人とその同盟者を大いに悩ませた。スペイン人を当惑させたのは、戦闘中、これらの先住民が手に小さな鈴を持ち、できる限り大きな音を立てたことであった。それはおそらく呪具として、あるいは敵を怯えさせるために用いられたのだろう。

フアロスはさらに、これらの部族がアルバラードの侵入によって征服されたのではなかったと付け加える。服属させるには、1526年、ドン・ペドロ・ポルトカレロによる新たな努力が必要だった。

彼らが頑強だったため、多数が奴隷として売られ、焼印を押された。シンカ族が住んだ川のスペイン語名 Río de los Esclavos、すなわち「奴隷川」は、ここから生まれた。

初期の記録には、彼らの社会状態を示す手がかりがほとんどない。〔原刊 p. 91〕その国は人口が多く、町は石ではなく木で建てられ、彼らは弓矢に熟達した勇敢な戦士だったという。小規模で独立した諸部族が一種の連合を結び、その *cabeza de señorío*、すなわち中心氏族は「名高い町グアサカパン」にあった。これに従属ないし同盟した四集団として、次の名が挙げられる。

|  |  |
|---|---|
| Nestiquipaque | Guaimango |
| Chiquimulilla | Guanagazapa |

私が提示する言語資料は、シンカ語三方言の語彙である。

第一のシナカンタン方言は、グアテマラの高名な歴史家・古物研究家ドン・フアン・ガバレテが、1868年に同地の出身者から採録した。他の二つは同年、フティアパの司祭ドン・セバスティアン・バルデスが彼のために採録した。シュトル博士によれば、ガバレテ氏の死後、原本は所在不明になったという。したがって、現存が知られるシンカ語の唯一の標本を提示する本公刊は、なおさら時宜を得ている。これらがほかの貴重な文書とともに、故C・ヘルマン・ベレント博士のコレクションから私の手に入ったことも付け加えておきたい。

## シンカ語の音韻

この言語は母音が豊かで、喉音や粗い口蓋音が少なく、この点でカクチケル語その他のマヤ諸方言と対照をなす。唇音 *b, f, v* は存在しない。ただし、添付した語彙の二、三語には *b* が見える。舌音は目立たず、*d* と *th* はまったく現れない。半母音 *r* と *l* は方言間で交換可能であり、ときに *n* とも交替する。

語彙表の文字はスペイン語アルファベットの音価をもつ。ただし *x* は英語 *she* の *sh* のように発音し、*v* は英語 *but* の中性母音、*z* は *s* と同じで、複字 *csh* と *sch* は *x*（＝ *sh*）の音価をもつらしい。

## 語彙についての注釈

**男。** *Jamu*。ホンジュラスのヒカケ語では *jome* ＝「男」である。しかし37語を比較して近い類似はこれ一つだけなので、私は偶然と考える。*jurac* はカクチケル語 *hun uinak*「一人の男」にわずかに似る。

**父。** *tataj* は明らかに父を指す普遍的な幼児語であり、系統関係をたどるうえでその類似には価値がない。母を意味する *utaj* についても同じである。ドイツ語 *Vater, Mutter*、カクチケル語 *tata* と比較されたい。

**息子。** *utajuum*。ポコムチ語では *akun*。おそらく偶然の類似である。

**娘。** *jaya najuun* の *jaya* は明らかに *aya*「女、雌」に由来し、したがって「女の子」を意味する。この組み合わせから、*najuun* は「息子」ではなく「子、子孫」を意味することがわかる。

**兄弟。** *xuyam* と *keruke* は明らかにまったく異なる語であり、男女の話者が別々に使うか、一方が兄に、他方が弟に適用されるのであろう。

**髪。** *muxl jumatan*（最後の語は疑いなく *jamatan* の誤り）は、文字どおりには「頭の指」、より適切には「頭の末端、小枝」を意味する。「指」の項を見よ。*musal* は *mux* と *gesalia* を合成したもので、同じ意味をもつらしい。このような複合語は、シンカ語がマヤ諸方言より総合的であることを示す。

**鼻。** *narin, narica* はスペイン語 *nariz*「鼻」かもしれない。

**歯。** *xa’jan* と *sajac* は「口」を意味する。接頭辞 *jari* は、*jaricomon*「膝」（膝蓋骨か）にも再び現れるので、骨または前面のどちらかを意味するらしい。

**胸。** *tutu* はスペイン語 *teta* かもしれないが、マヤ諸方言にはカクチケル語とキチェ語 *tu, tit*「乳房」、ポコマム語 *tuj*、チョル語 *txu* がある。*ziquim* はキチェ語 *tz’um*「乳房」と関係するかもしれない。

**手。** *jixi pum* はおそらく「腕の末端」である。マヤ諸方言のどれにも「手」だけを指す語はない。手と腕は一語に含まれ、その適切な訳は「上肢」である。手と腕を区別したいときは複合語を作るか、その区別を聞き手に委ねなければならない。*Jixi* は「石」としても挙げられている。矢の石製の尖端ないし端部が、この表現の同一性を説明するのかもしれない。

**指。** *mux* については「歯」の項を見よ。*pere pu* は *pum*「上肢」と、おそらく端、先端、枝を意味する接頭辞とからなる。

**脚。** *uapi* は「足」を意味する。該当項を見よ。

**膝。** 「歯」の項を見よ。挙げた二語は明らかに異なるものを意味する。

**足。** *uapan*。カクチケル語 *akan* と比較せよ。

**町。** *machiname*。これは明らかにピピル語 *chinamitl*「町」に接頭辞 *ma* を付したものである。

**臼。** スペイン語 *piedra de moler*。女性がトウモロコシを搗く、くぼんだ石である。

**皿。** 原資料では *comal*。ナワトル語 *comalli* に由来し、トルティーヤを調理するために使う浅い土器である。

〔原刊 p. 95〕

**トウモロコシ。** トウモロコシおよびその穂を指す語として挙げた *aima* は、チョンタル語にまったく同じ形で、レンカ語には *ama* として見える。私はこれを、マヤ語族でトウモロコシを表す普遍的な語 *ixim*（*ishim* と発音）から導きたいと思う。さらに後には畑を表す *uaya’a* があり、カクチケル語 *auan*「トウモロコシ畑」、または作物が若いときの *auex* に近い。これが正しければ、近隣諸部族がマヤ系民族からトウモロコシ栽培を学んだことを示す。これは、植物学者が現在、*Zea mais* の原生地はグアテマラで、野生の *Euchlena luxurians* から人為的に作り出されたと考えているだけに、いっそう意味深い。トウモロコシを指すもう一つの語 *ahua* は「月」を表す語と同じである。これは、月をトウモロコシの女神と同一視したことを指すのかもしれない。チペワ語でトウモロコシは *mandamin*、すなわち「神 *manito* の穀粒 *min*」である。

**豆。** *xin’ac* はカクチケル語 *tzinak*、ツェンダル語 *txenek* である。明らかにシンカ族は、まずマヤ系の隣人からトウモロコシと豆を得た。

**塩。** *tita* はナワトル語 *iztatl* に由来する。シンカ族はこの品を、ナワトル語を話す隣人ピピル族から知った。

**半ズボン。** 三語ともスペイン語 *calzones* が崩れたものである。

**紙。** これらの語はスペイン語 *papel* が崩れたものである。

**天または空。** *uina’* はツォツィル語 *uinajel* と近縁である。

**太陽と月。** 純粋なマヤ語では、太陽の一般的な語根は *ki*、月は *u* である。しかしケクチ語、ポコムチ語、ポコマム語では、月に対してまったく異なる *po* という語がある。これはシンカ語 *parri*「太陽」の語根らしい。さらにチャナバル語とマム語には月を表す *ixa’u* があり、*ix* はおそらく女性を表す接頭辞なので、月を表す *a’u* が残り、シンカ語 *ahua* と同系である。

*ahua* という語は *huy*「水」と表面的には似る。しかし、これらの言語を詳しく調べても、太陽と水を表す語には語根的な関係があるとするトランブル博士の説は裏づけられない（*Proceedings of the American Philological Association*, 1875–76, p. 45 を参照）。

**星。** *xune* はカクチケル語 *tzumil*「星」と同系である。*hueso* はマヤ諸方言と何の関係もないように見える。

**日。** *pari*。太陽と同じである。

**夜。** *chijmac*。カクチケル語 *aka*「夜」に、おそらく前置詞 *chi*「で」を伴ったもの、すなわち「夜に」である。

**風。** *yeuha*。ポコムチ語 *te’ug*。

**木。** *utis*。ツェンダル語 *te*、チョル語 *tie’*。

**ジャガー。** *uilay*。ポコムチ語 *ba’lam*。

**鹿。** *tuma*。チョンタル語 *chima’*。

**ペッカリー。** *cargua* は *caragua*「森」に由来する。*jaxo* はポコムチ語 *aj’k*「豚、野生の豚」。同じ動物を指すポコムチ語の名 *quiche ajk*「森の豚」と比較されたい。

**犬。** *pelo* はスペイン語 *perro*。

**魂。** *terouala*。このうち *tero* は形容詞「死んだ」である。

〔原刊 p. 96〕

**生きている。** *ixij*。アグアカテカ語 *itzin*、ツェンダル語 *chuxul*。

**老いた。** *mochi*。マヤ語 *noxib*、ツォツィル語 *molol*。

**色。** 色名はすべてマヤ語とまったく異なる。語根に一般的な接尾辞 *ati* を付したものらしい。

| 語根 | 色 | 語根 | 色 |
|---|---|---|---|
| *mo* | 白 | *teu* | 赤 |
| *sim* | 黒 | *tot* | 黄 |
| *me* | 青または緑 |  |  |

黄色を表す *meelati* はおそらく誤りであり、青と緑を同一の語根で表すことは、中央アメリカ諸語の大半に共通する。私は別のところでもこれを指摘した（*The Names of the Gods in the Kiche Myths*, *Proceedings of the American Philosophical Society*, 1881）。

比較のため、キチェ方言に見えるマヤ語の色彩語根を加える。

| 語根 | 色 | 語根 | 色 |
|---|---|---|---|
| *zak* | 白 | *cak* | 赤 |
| *gek* | 黒 | *gan* | 黄 |
| *rax* | 青または緑 |  |  |

両者にわずかな関係すらないことは明白であり、シンカ語の色名はピピル語およびアステカ語の色名からも同じように遠い。

**数詞。** 私が比較した中央アメリカおよびメキシコ南部の他言語に対して、数詞が示す類似はわずかで、しかも弱い。*ica*「一」はマンゲ語 *tica* に似る。また最初の四数詞は、次のようにホンジュラスのレンカ語と比較できる。

| 数 | シンカ語 | レンカ語 |
|---:|---|---|
| 1 | ica | ita |
| 2 | piar | pe |
| 3 | uala | lagua |
| 4 | jiria | aria |

しかし、私が比較したレンカ語四方言の残りの語彙によって裏づけられないため、これは偶然だと考える。

ハラパ方言の語末 *-ar* は、かなり純粋なマヤ方言であるイシル語の数詞に見える、回数ないし反復を表す接尾辞 *ual* を思わせる。たとえば次のとおりである。

- *unguual*――一回。
- *cavuual*――二回。
- *ox ual*――三回、など。

**神。** *tiuix*。ガバレテはこの語に次の注を付す。「厳密には神を意味せず、像または偶像を意味する。現在では聖人像に用いられる。」おそらくカクチケル語 *tioh*「偉大な、神聖な」という宗教的な意味で使われる語に由来する。これは彼らの古代祭祀の起源を示す。

数の五 *puj-ar* は、明らかに名詞 *puj*「手」であり、五本の指を指す。

〔原刊 p. 97〕

六 *tacal* は *ti-ical*「第二の一」、すなわち第二の手の第一指、の複合語らしい。七 *puj-ua* と八 *a-puj* にも *puj*「手」という語が含まれているらしい。

この分析から、シンカ族はマヤ族またはピピル族（ナワ族）とは異なる語族に属した、との結論に達する。彼らは素朴な部族であり、トウモロコシと豆の栽培をカクチケル族またはポコマム族から初めて学び、宗教儀礼の一部も同じ人々から学び、塩の使用と村落組織の一部をピピル族から、現在の服装の一部をスペイン人から取り入れた。

彼らが話したのは、単音節語根をもち、語幹が主として接尾辞で形成される、母音の豊かな言語であった。

彼らはかつてグアテマラ全域に広がっていた素朴な先住民で、マヤ人とナワ人という好戦的な二民族の移住により海岸へ追いやられ、最初に発見された狭い地域へ押し込められたのかもしれない。この二民族はいずれも、自らが外部から来たことをはっきり記憶していた。

カクチケル族とポコマム族がグアテマラへ到来した年代について、われわれはほとんど知らない。しかし征服直後にフランシスコ・エルナンテス・アラナ・シャヒラが著した『カクチケル年代記』には、その伝承的な歴史が保存されており、その原写本は私の所蔵にある。彼によれば、祖先がグアテマラへ入ったとき、広大な土地は無人であった。別の地域には、カクチケル族から見ても野蛮で、*chicop*「獣」と呼ぶほど未開な民族が住んでいた。彼らはその二人を捕虜とし、低地へ入ったとき、その者たちからいくつかの語を学んだ。年代記作者は続ける。

「彼ら〔すなわちカクチケル族の祖先〕は最後にチョルマグとスチタンへ下った。そこの言語は非常に難しく、野蛮人自身だけがその言語を話すことができた。われわれは野蛮人ロシュピンとチュピチン〔彼らの捕虜〕に尋ねたとおりに話しただけであり、到着すると『*uaya, uaya, ela opa*』と言った。野蛮人たちは、われわれがチョルマグの住民と彼らの言語で話すのを聞いて非常に驚いた。本当に怯えていた。しかし、彼らはわれわれによい言葉だけを与えた。」

意味のわからないこれら少数の語からも、その言語がマヤ語やナワトル語とはまったく別の系統だったことは明らかである。それはシンカ語のように柔らかく母音が豊かであり、実際、*ela*「舌（言語か）」は語彙表に見える。残念ながらシャヒラは、挙げた句の意味を教えてくれない。おそらく何らかの友好的な挨拶だったのであろう。

しかし、この考察をさらに進めるだけの価値はない。以上の示唆はシンカ語に付随する関心を明らかにし、願わくは誰かを励まして、それについてさらに完全な情報を得させるであろう。
